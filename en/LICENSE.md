## About "No GPL Contamination"

Mirage contains no MySQL source code; the MySQL protocol is independently implemented.
Paper / Folia APIs are referenced **at compile time only** and are **not bundled into the
delivered jars**, so there is no GPL contamination. See the component list in [../NOTICE](../NOTICE).
